# Template Wawancara Pengguna

Gunakan satu salinan untuk tiap sesi dengan 3–5 pemilik atau pengelola UMKM makanan. Catat jawaban sebagaimana disampaikan. Minta persetujuan sebelum merekam dan gunakan kode responden saat merangkum.

| Kolom | Catatan |
|---|---|
| Kode responden, tanggal, dan peran | |
| Produk utama dan frekuensi produksi | |
| Bahan dan jumlah pemasok yang biasa dipakai | |
| Persetujuan pencatatan atau rekaman | |

## Pertanyaan

1. Kapan terakhir bahan terlambat atau gagal datang? Produk mana yang terpengaruh dan apa keputusan Anda saat itu?
2. Bagaimana mencari dan memilih pemasok alternatif? Informasi apa yang paling penting sebelum membeli?
3. Di mana stok, resep atau kebutuhan bahan, permintaan, dan biaya dicatat? Mana yang paling sulit diperoleh?
4. Berapa lama biasanya menentukan rencana produksi saat stok berubah? Bagian mana yang memakan waktu?
5. Setelah mencoba demo, apa arti bahan pembatas dan estimasi kontribusi setelah biaya tambahan pasokan menurut Anda?
6. Apakah Anda dapat menjelaskan kenaikan produksi pada skenario mitigasi? Informasi apa yang dibutuhkan untuk membuat keputusan sungguhan?

| Observasi | Catatan |
|---|---|
| Lama menemukan bahan yang terdampak | |
| Lama menjalankan gangguan dan mitigasi | |
| Hambatan, istilah membingungkan, atau kebutuhan data lanjutan | |
| Kutipan yang disetujui untuk penggunaan anonim | |
